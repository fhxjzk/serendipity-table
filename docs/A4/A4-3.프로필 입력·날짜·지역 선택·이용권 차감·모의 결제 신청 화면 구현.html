프로필 입력·날짜/지역 선택·이용권 차감/모의 결제 신청 화면 구현

A4-3
워크프로필·일정 선택·모의 결제 신청 플로우
관련 기능F-02~05 프로필·동의 · F-07~10 회차 조회·신청 · F-11 이용권 · F-12 환불 규정 · F-13 모의 결제 · F-14 결제 기한 · F-78 프로필 불러오기 (02.기능 명세서 번호)
목표처음 온 참가자가 모바일에서 프로필 입력부터 결제까지 한 흐름으로 마친다.

구현 내용

  • 기본 정보·매칭 프로필(MBTI·관심사·성향·원하는 사람)·식사 조건·동의 입력. 잘못된 값은 입력창 옆에 오류를 보여 준다.
  • 모집 중 회차에서 날짜·지역 복수 선택 후 신청. 중복 신청·참가 제한자는 막는다.
  • 보유 이용권이 있으면 차감, 없으면 모의 결제(쿠폰 자동 적용, 연속 클릭 중복 결제 방지).
  • 결제 기한 안내 → 기한이 지나면 자동 만료되어 매칭에서 빠진다. 결제 완료 시 알림·이메일 발송.
  • 재신청 때는 저장된 프로필을 불러와 다시 입력하지 않아도 된다.
