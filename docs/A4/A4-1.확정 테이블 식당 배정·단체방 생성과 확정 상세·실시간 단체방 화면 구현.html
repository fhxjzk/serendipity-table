우연한 식탁 MVP · 구현 결과서 · A4. 참가자 앱

확정 테이블 식당 배정·단체방 생성과 확정 상세·실시간 단체방 화면 구현

A4-1
워크확정 상세·시스템 메시지 단체방 화면
관련 기능F-35 식당 자동 배정 · F-36 확정 알림·모임 정보 · F-37 단체방 생성 · F-38 공지·큐레이션 · F-42 실시간 대화 (02.기능 명세서 번호)
목표확정된 참가자가 ‘어디서, 언제, 누구와’를 한 화면에서 확인하고 같은 식탁 사람들과 바로 대화할 수 있게 한다.

구현 내용

  • 홈의 티켓 카드(날짜·식당·시간·D-day)에서 확정 상세로 이동한다.
  • 확정 상세: 식당명·주소·지도 링크·예약명·식사 조건 요약과 좌석도(구성원 자리 카드)를 보여 준다.
  • 확정과 동시에 테이블 단체방이 만들어지고 구성원이 자동 초대된다.
  • 단체방에는 확정 안내·큐레이션·식사 조건 같은 시스템 메시지가 종류별 모양으로 표시된다.
  • Supabase Realtime으로 새 메시지가 새로고침 없이 바로 보인다. 같은 테이블 구성원만 읽고 쓸 수 있다(RLS).

코드 위치

  • web/src/app/(participant)/applications/[id]/table/
  • web/src/app/(participant)/chat/[roomId]/
  • web/src/components/table-seats.tsx
  • supabase/migrations/…000600_finalize_tables.sql

확인 방법 (04.테스트 체크리스트)

TC-10확정 후 자동 안내(식당·단체방)
TC-12실시간 단체방: 확정된 참가자 + 같은 식탁 참가자(시크릿 창)
결과 — 두 계정 창에서 메시지가 즉시 오가는 것 확인. 다른 테이블 사람은 단체방에 들어갈 수 없음.
