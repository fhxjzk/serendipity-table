선호 점수 5항목 계산·60점 기준 자동 확정 구현

A3-3
워크선호 점수화·최소 점수 기준 자동 확정
관련 기능F-26 선호 점수 계산 · F-29 자동 확정 (02.기능 명세서 번호)
목표필수 조건을 통과한 테이블이 ‘좋은 조합’인지 점수로 판단하고, 기준을 넘으면 사람 손 없이 확정한다.

구현 내용

  • 테이블 점수(0~100) = 5개 항목의 가중합. 가중치는 설정값(app_settings.match_weights)에서 읽는다.
  • 항목가중치계산
    성비 균형30남녀가 같을수록 1
    MBTI 궁합25N/S 같음 0.5 + E/I 다름 0.3 + J/P 같음 0.2
    관심사20겹치는 관심사 2개 이상이면 1
    원하는 성향15원하는 사람 유형과 맞는 비율
    새 만남10이전에 만난 적 없는 비율
  • 점수가 최소 기준 60점(min_match_score) 이상이면 자동 확정, 미만이면 다른 조합을 시도한다.
  • 항목별 점수를 저장해 운영자 매칭 모니터·미리보기에서 왜 이 조합인지 볼 수 있다.

코드 위치

  • web/src/lib/matching/finalize.ts
  • web/src/lib/matching/finalize.test.ts
