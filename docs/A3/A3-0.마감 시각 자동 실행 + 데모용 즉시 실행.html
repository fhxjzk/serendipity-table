(워크 산출물) 마감 시각 자동 실행 + 데모용 즉시 실행

A3-0
워크마감 시각 자동 실행 + 데모용 즉시 실행
관련 기능F-22 마감 시각 자동 실행 · F-32 멱등 실행 · F-76 시점 즉시 실행 · F-77 테스트 참가자 일괄 생성 (02.기능 명세서 번호)
목표운영자가 버튼을 누르지 않아도 신청 마감 시각이 되면 매칭이 자동으로 돌고, 시연 때는 원하는 단계를 바로 실행할 수 있게 한다.

구현 내용

  • Supabase pg_cron이 1분마다 /api/jobs/tick을 호출한다. 비밀 키(CRON_SECRET)가 없으면 401로 거절한다.
  • tick은 마감이 지난 회차의 매칭, 행사 1일 전 리마인드, 행사 시작·종료, 노쇼 확정, 발송 재시도를 차례로 처리한다.
  • 회차마다 작업 키를 두어 같은 작업이 두 번 실행되지 않는다(스케줄러와 즉시 실행이 겹쳐도 1회).
  • 운영자 › 매칭 모니터의 진행 단계 패널: 매칭 즉시 실행 → 리마인드 → 시작 → 종료 → 노쇼 확정을 버튼으로 실행한다.
  • 시연 참가자 13명 만들기: 재배치와 나이 차이 실패가 반드시 나오도록 구성된 가상 참가자를 한 번에 만든다.
  • 시연 회차는 자동 진행을 멈춰 두어(auto_match=false) 시간이 지나도 시연 장면이 유지된다.
