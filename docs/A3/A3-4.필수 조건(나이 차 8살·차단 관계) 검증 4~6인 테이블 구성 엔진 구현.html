필수 조건(나이 차 8살·차단 관계) 검증 4~6인 테이블 구성 엔진 구현

A3-4
워크필수 조건 검증으로 4~6인 테이블 생성
관련 기능F-23 매칭 대상 선별 · F-24 관계 이력 반영 · F-25 필수 조건 검증 · F-27 테이블 구성 (02.기능 명세서 번호)
목표어떤 경우에도 어기면 안 되는 조건을 먼저 지키고, 그 안에서 4~6명 테이블을 만든다.

구현 내용

  • 매칭 대상: 마감 시각까지 결제 완료된 신청만. 미결제·취소·참가 제한자는 제외한다.
  • 필수 조건: 테이블 인원 4~6명(table_size), 최대 나이 차 8살(max_age_gap), 차단·신고 관계인 두 사람은 같은 테이블 금지.
  • 관계 이력: 과거에 함께 앉았던 사람은 피하고, ‘다시 만나고 싶음’을 고른 사람은 우선 고려한다.
  • 같은 날짜·지역 신청자끼리 먼저 묶고, 남는 사람은 재배치 단계로 넘긴다.
  • 엔진은 DB와 분리된 순수 함수라 같은 입력이면 항상 같은 결과가 나오고 단위 테스트가 쉽다.

코드 위치

  • web/src/lib/matching/engine.ts, types.ts
  • web/src/lib/matching/run.ts (설정·후보 불러오기)
  • web/src/lib/matching/engine.test.ts

확인 방법 (04.테스트 체크리스트)

TC-06단위 테스트 + 150명 무작위 풀 실행: 모든 테이블 4~6명, 나이 차·차단 위반 0건
결과 — 무작위 풀 실행에서 필수 조건 위반 0건. 테스트 19개 전체 통과(npm test).
