확정 테이블 식당 자동 배정·단체방 생성·시스템 안내·확정 알림 처리 구현

A5-8
워크확정 후 식당 자동 배정·단체방 생성·안내 알림 예약
관련 기능F-35 식당 자동 배정 · F-36 확정 알림 · F-37 단체방 생성 · F-38 공지·큐레이션 · F-45 배정 재시도 (02.기능 명세서 번호)
목표테이블이 확정되는 순간, 식당 예약부터 안내까지 사람 손 없이 끝낸다.

구현 내용

  • 확정된 테이블마다 같은 지역·남은 재고가 있는 식당을 자동 배정하고 예약명을 만든다.
  • 식당이 부족하면 예외 처리함에 올리고, 스케줄러가 매분 재배정을 시도한다(나중에 성공하면 예외 자동 해결).
  • 단체방 생성 + 구성원 초대 + 확정 안내·큐레이션·식사 조건 시스템 메시지를 템플릿으로 게시한다.
  • 확정 알림을 즉시 보내고, 참가자 수신 설정에 따라 웹 푸시·이메일 발송 대기열에 넣는다.
  • 위 과정은 DB 함수 하나에서 처리되어 일부만 된 상태가 남지 않는다.
