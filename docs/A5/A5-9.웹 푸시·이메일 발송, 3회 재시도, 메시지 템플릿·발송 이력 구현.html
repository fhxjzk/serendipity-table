웹 푸시·이메일 발송, 3회 재시도, 메시지 템플릿·발송 이력 구현

A5-9
워크확정 후 식당 자동 배정·단체방 생성·안내 알림 예약
관련 기능F-40 웹 푸시 · F-41 이메일 · F-45 재시도 · F-70 메시지 템플릿 · F-71 발송 이력 (02.기능 명세서 번호)
목표앱을 열지 않아도 중요한 안내가 도착하고, 실패하면 알아서 다시 보낸다.

구현 내용

  • 웹 푸시(PWA): 매니페스트·서비스 워커·구독 저장(VAPID). 아이폰은 홈 화면 설치 안내.
  • 이메일(Gmail SMTP, 보낸 사람 ‘우연한 식탁’): 결제 완료·매칭 확정·실패·1일 전·환불 완료 5종, 종류별 수신 설정.
  • 알림이 생기면 발송 대기열에 쌓이고 다음 1분 안에 발송. 실패 시 1·2분 간격 3회 재시도 → 그래도 실패하면 예외 처리함, 나중에 성공하면 자동 해결.
  • 메시지 템플릿 9종을 운영자가 수정({식당명} 같은 변수 치환), 수정 전후는 변경 이력에 기록.
  • 발송 이력: 채널·결과 필터, 받는 사람·시도 횟수·오류, 다시 보내기·지금 보내기.
