FAQ·1:1 문의 자동 답변과 운영자 답변 연결 구현

A5-3
워크회차 생성·예외 처리함·대시보드 구현
관련 기능F-85 FAQ·문의 자동 답변 (02.기능 명세서 번호)
목표자주 묻는 질문은 자동으로 답하고, 답할 수 없는 문의만 운영자에게 넘긴다.

구현 내용

  • 참가자 고객센터: FAQ 목록과 1:1 문의 작성.
  • 문의를 등록하면 FAQ와 맞춰 자동 답변을 바로 단다(예: 환불 기한 질문 → 환불 규정 답변).
  • 자동 답변이 안 되는 문의는 운영자 예외 처리함에 올라가고, 운영자 답변이 참가자 화면과 알림으로 전달된다.
  • 문의 자동 해결률은 대시보드 지표로 집계된다.

코드 위치

  • web/src/app/(participant)/support/
  • web/src/app/admin/exceptions/
  • supabase/migrations/…001200_support.sql
