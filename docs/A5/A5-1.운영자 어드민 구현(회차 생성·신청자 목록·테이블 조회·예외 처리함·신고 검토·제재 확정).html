운영자 어드민 구현(회차 생성·신청자 목록·테이블 조회·예외 처리함·신고 검토·제재 확정)

A5-1
워크회차 생성·예외 처리함·대시보드 구현
관련 기능F-57 권한·변경 이력 · F-58 회차 생성 · F-60 신청자 목록 · F-64 테이블 조회 · F-66 예외 처리함 · F-68 신고 검토·참가 제한 · F-75 상태 이력 (02.기능 명세서 번호)
목표운영자는 자동화가 처리하지 못한 ‘예외’만 보고 처리한다.

구현 내용

  • /admin은 운영자만 접근. 운영자 작업마다 이전·이후 값을 변경 이력에 남긴다.
  • 회차 생성·수정: 날짜·시간·지역별 정원.
  • 신청자 목록: 회차(전체 포함)·지역·상태·매칭 결과·이름 필터, 참가자별 이력 화면.
  • 테이블 조회: 구성원·식당·예약명·식사 조건·운영 안내 발송 수(참가자 대화 내용은 보지 않음).
  • 예외 처리함: 식당 부족·발송 실패·노쇼 이의·문의 등 사람 판단이 필요한 건을 모아 처리.
  • 신고 검토: 신고 내용 확인 → 참가 제한(제재) 확정 또는 기각.
