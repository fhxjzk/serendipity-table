알림함·전날 리마인드·행사 시각 대화 주제 3개+아이스브레이킹 자동 게시 구현

A5-7
워크대화 콘텐츠 3개 이상 행사 시각 자동 게시
관련 기능F-39 앱 내 알림 · F-43 1일 전 리마인드 · F-44 대화 주제·아이스브레이킹 (02.기능 명세서 번호)
목표처음 만난 사람들이 어색하지 않게, 정해진 시각에 대화 거리를 자동으로 건넨다.

구현 내용

  • 알림함: 종류별 알림, 읽음 처리, 안 읽은 개수 배지.
  • 행사 1일 전 리마인드: 단체방 공지 + 알림(시간·장소·예약명).
  • 행사 시작 시각에 단체방에 대화 주제 3개 이상 + 아이스브레이킹을 자동 게시. 주제 30건 중 구성원 관심사와 맞는 것을 고른다.
  • 모든 게시는 스케줄러(1분 주기)가 처리하고, 시연 때는 운영자 진행 단계 버튼으로 바로 실행한다.
